# Fictional sample screenshots

These are authentic browser captures of the exported sample app running locally. Both show `/work`: desktop at 1280 × 800 and Pocket at 390 × 844. They were visually reviewed before publication.

- [Desktop preview](desktop.jpg): windowed Portfolio, launchers and sample widgets.
- [Pocket preview](pocket.jpg): category filters, fictional case cards and bottom navigation. The list continues below the visible area.

All profile names, organizations and narratives are fictional. Geometric sample assets replace original media. No personal photographs, credentials, private content, browser chrome or local file paths are shown. The desktop visitor display is illustrative; service availability and clock/weather values vary between runs.

[`review.json`](review.json) records each file's SHA-256 digest, dimensions and sample route. The publishing checks accept only these two reviewed JPEG paths, verify their bytes/dimensions and reject EXIF, comments, profiles and embedded thumbnails. Original image/video files remain excluded.

If you customize your own copy, capture and review your own screenshots and update their review records before replacing these files. The upstream publisher maintains a separate private approval record for its own captures.
