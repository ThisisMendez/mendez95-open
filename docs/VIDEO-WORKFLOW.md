# Video production workflow

The original project used Explainroo for two complementary videos: a product/experience walkthrough and an implementation walkthrough. Their recordings, narration, finished masters and original autobiographical scripts are personal material and are excluded from this edition.

A reproducible process for your own project:

1. Write a short script organized by scene and a storyboard describing the visual evidence.
2. Capture authorized desktop/mobile interactions and implementation excerpts. Check the browser chrome, source viewer, notifications and frame edges for personal information.
3. Keep the script, scene code and `video.json` together in an Explainroo project. Keep provider credentials outside the project.
4. Generate narration, run Explainroo checks, render, and verify the final mix using the installed version's documented commands.
5. Decode the entire output, inspect frames across the timeline, check captions/audio, and test browser playback and seeking.
6. Add only reviewed final assets to your own fork and connect them through the reusable video player.

For the original two-video structure, aim for about 60 seconds for product decisions and 88 seconds for implementation. These are editorial targets, not a guarantee of render duration. Consult your installed Explainroo documentation for current configuration and CLI options.
